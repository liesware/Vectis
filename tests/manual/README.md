# Manual HTTP Happy Path

Run the local walkthrough from the repository:

```sh
python3 tests/manual/http_happy_path.py
```

It builds the development binary with Cargo. To use an existing executable or
retain the laboratory after success:

```sh
python3 tests/manual/http_happy_path.py --binary target/debug/vectis --keep-lab
```

The tool uses Python's standard library and a private temporary directory with
SQLite, the official schema, signed configuration, init material and logs. It
does not read the repository's `.env`, use your database, import integration-test
helpers or run through CI/`tests.sh`. An unused loopback port is chosen at startup.

One API key is generated by `init` and reused throughout. It initially acts as
root to create one KID and configure the laboratory. The server then restarts
with root authentication disabled; that same key authenticates through signed,
explicit grants without `admin`. One subject is created and shared by the stored
token, deterministic token, FPE and symmetric flows. Profiles use synthetic data;
each batch request contains exactly three distinct refs. Sharing is 3-of-5 and
combines three nonconsecutive shares; it is not a batch operation.

Every operation prints Markdown immediately: method/path, request, HTTP status,
duration, real response and result. Requests are chained from fresh responses:
encrypt precedes decrypt, create precedes verify, split precedes combine. The
tool checks success, recovered values and batch ordering, not negative/security
matrices. Token deletion, subject deletion and KID retirement happen last.
Health readiness polling during startup is internal and is not printed.

All `/message...` endpoints and `/metrics` are excluded; local `/symmetric...` endpoints are
included. `/time/attest` contacts the real default Cloudflare NTS/Roughtime
sources and **requires working external connectivity**. A `502` or timeout is a
failure, not a substitute success. A valid `200` is accepted whether or not
`server_clock.acceptable` is true. No source or trust-anchor override is applied.

API keys, API-key hashes and unseal material are redacted from the transcript.
Synthetic plaintexts, tokens, openings and shares are intentionally displayed so
the flows can be inspected. Do not adapt this output mechanism for real patient
or production data.

The first failure stops the walkthrough and returns exit code 1. The server is
always stopped, including on Ctrl-C. Successful runs remove their laboratory
unless `--keep-lab` is set; failed runs retain it and print its location and the
`server.log` path. Command failures produce a sanitized `command.log`. Retained
labs contain private init/unseal material and must be handled as secrets and
deleted when no longer needed. They are not production backups.

Run the offline regressions without starting a server or contacting Cloudflare:

```sh
python3 -m unittest discover -s tests/manual -p 'test_http_happy_path.py' -v
```

The implementation separates transport/rendering (`happy_transport.py`), process
and configuration setup (`happy_lab.py`) and ordered flows (`happy_flows.py`).
Add a happy path beside its family, reuse the existing KID/subject, and keep
batch inputs at three items. No production contracts are changed by this tool.
